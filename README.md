# Core Banking System - Phase 1: Accounts Management 🏦💻

مشروع هندسي متكامل لبناء نواة نظام بنكي (Core Banking System) لإدارة حسابات العملاء، تم تصميمه وتطويره بالكامل بتطبيق مفاهيم البرمجة كائنية التوجه (OOP) المتقدمة في لغة ++C، والاعتماد على الملفات النصية كقاعدة بيانات مدمجة.

## 🛠️ الميزات المعمارية المطبقة في هذا الكلاس (clsBankClient)
- **State Management (enMode)**: إدارة حالة كائن العميل ديناميكياً داخل الميموري (فارغ، تحديث، أو إضافة جديدة) لضمان سلامة العمليات قبل الحفظ.
- **Safe Delete Logistics**: تطبيق آلية الحذف الآمن عبر وسم السجلات `_MarkedForDelete` وتصفية الملفات أثناء الحفظ لمنع الفقدان المفاجئ للبيانات.
- **Advanced Properties**: عزل وتأمين رقم الحساب والبيانات المالية الحساسة عبر الخصائص المتقدمة والمحاطة بـ `__declspec`.
- **File Database Engine**: بناء دوال داخلية مشفرة بالـ `private` لتقطيع السطور (`Split`) وتحويل الكائنات إلى نصوص متوافقة مع قاعدة البيانات النصية والعكس تلقائياً.

## 📈 خارطة الطريق الحالية والمستقبلية للنظام (System Roadmap)
- [x] **المحطة الأولى (الحالية):** بناء النواة الصلبة لإدارة الحسابات والـ CRUD وسجلات الملفات.
- [ ] **المحطة الثانية:** واجهة المستخدم الشاملة (Main UI Screens).
- [ ] **المحطة الثالثة:** نظام العمليات المالية الشامل (Transactions: Deposit & Withdraw).
- [ ] **المحطة الرابعة:** إدارة المستخدمين وصلاحيات الموظفين (Users & Permissions Matrix).
- [ ] **المحطة الخامسة:** الحوالات والتشفير المعقد لبيانات الأمان (Transfer Logs & Encryption).

## 🚀 كيفية استخدام الكلاس في الـ Main
تستطيع استدعاء دالة البحث مباشرة للتأكد من وجود العميل، ثم استخدام دالة الحفظ الآمنة:
```cpp
if (clsBankClient::IsClientExist("A101")) {
    clsBankClient Client = clsBankClient::Find("A101");
    Client.AccountBalance = 8500; // تعديل الرصيد بالخاصية
    Client.Save(); // حفظ تلقائي في الملفات
}
```
