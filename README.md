# Core Banking System - Phase 2: Security, Users & Transactions 🏦💸🔐

مشروع هندسي متكامل لبناء نظام بنكي (Core Banking System)، تم تصميمه وتطويره بالكامل بتطبيق مفاهيم البرمجة كائنية التوجه (OOP) المتقدمة في لغة ++C، والاعتماد على بنية الشاشات المنفصلة المعتمدة على الوراثة (Modular Screen Inheritance).

## 🛠️ الميزات المعمارية المطبقة في هذه المرحلة
- **Transactions Engine**: محرك مالي متكامل لمعالجة عمليات السحب والإيداع الآمن، وحساب إجمالي أرصدة البنك وتحديث قاعدة البيانات النصية لحظياً.
- **Users Management CRUD**: نظام كامل لإدارة الموظفين والمستخدمين (إضافة، تعديل، حذف، واستعراض) مستقل وموازٍ لنظام العملاء.
- **Bitwise Permissions Matrix**: مصفوفة أمان رقمية صارمة لعزل وحظر الوصول إلى الشاشات الحساسة بناءً على الصلاحيات المخولة للموظف.
- **Circular Dependency Resolution**: إعادة هيكلة تدفق التحكم (Control Flow) للتنقل الآمن بين الشاشات دون استهلاك الذاكرة وحماية النظام من الـ Stack Overflow.

## 📈 خارطة الطريق المعمارية المفصلة للنظام (System Roadmap)
- [x] **المحطة الأولى:**
** بناء النواة الصلبة لإدارة الحسابات والـ CRUD للعملاء وسجلات الملفات.
- [x] **المحطة الثانية:**
** بناء محرك العمليات المالية (Transactions Module: Deposit, Withdraw, Total Balances).
- [x] **المحطة الثالثة:**
** بناء نظام إدارة المستخدمين والموظفين بالكامل (Users Management CRUD).
- [x] **المحطة الرابعة:**
** بناء شاشات الـ Login/Logout وتصميم معمارية تدفق التحكم (Control Flow).
- [x] **المحطة الخامسة (الحالية):**
** تطبيق مصفوفة صلاحيات المستخدمين الصارمة لعزل الشاشات (Permissions Matrix).
- [ ] **التمديد الأول (Extension 1):** بناء شاشة سجل حركات الدخول بالنظام (Login Register Screen).
- [ ] **التمديد الثاني (Extension 2):** تطبيق آلية عداد محاولات الدخول الخاطئة (Login Permissions).
- [ ] **التمديد الثالث (Extension 3):** حظر وقفل النظام التلقائي بعد 3 محاولات خاطئة (System Lockout).
- [ ] **التمديد الرابع (Extension 4):** بناء كلاس شاشة تحويل الأموال بين الحسابات (Transfer Screen).
- [ ] **التمديد الخامس (Extension 5):** بناء وتوليد سجل الحوالات المالية (Transfer Log Screen).
- [ ] **التمديد السادس (Extension 6):** عرض سجل الحوالات المكتمل واجهياً (Show Transfer Log).
- [ ] **التمديد السابع (Extension 7):** بناء خوارزمية تشفير كلمات السر بداخل الملفات (Password Encryption).
- [ ] **التمديد الثامن (Extension 8):** خوارزمية فك التشفير أثناء قراءة البيانات (Password Decryption).
- [ ] **التمديد التاسع (Extension 9):** شاشة تحديث بيانات المستخدمين المتقدمة (Update User Screen).
- [ ] **التمديد العاشر (Extension 10):** التجريد المعماري النهائي وتطبيق الـ Abstract Classes / Interfaces.
